# Onboard

Everything you need to install the harness in a project, and to keep it up to date.

- [**Get Started**](GET_STARTED.md): prerequisites, describing your project, installing, a first issue, upgrading, and what to do when something goes wrong.

The installer is [`install.cjs`](install.cjs) in this folder. The files it installs are in [`harness/.claude/`](../harness/.claude/).

The reference for each part is in [`Docs/`](../Docs/README.md).
