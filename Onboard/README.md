# Onboard

Everything you need to install the harness in a project, and to keep it up to date.

- [**Get Started**](GET_STARTED.md): prerequisites, describing your project, installing, a first issue, upgrading, and what to do when something goes wrong.

For now, the installer stays at [`scripts/install.cjs`](../scripts/install.cjs), and the files it installs at [`harness/.claude/`](../harness/.claude/). Moving them into this folder is planned in [#4](https://github.com/MatheusCastro99/ProdHarnessConfig/issues/4). It waits until the current version of the harness has been measured, so that a layout change doesn't land in the middle of that measurement.

The reference for each part is in [`Docs/`](../Docs/README.md).
